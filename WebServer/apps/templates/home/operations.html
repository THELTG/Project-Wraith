Local Privilege Escalation : Vulnerable Kernel Drivers Check
Vulnerable Kernel Drivers Check
This operation searches for any vulnerable drivers in the target system. It is recommended to bypass AMSI first before using this operation.

The operation compares the drivers present in the system against a list of known vulnerable drivers found in LOLdrivers (https://www.loldrivers.io/). Detected vulnerabilities require prompt action, as it could indicate the presence of a malicious driver or a driver that can be taken advantage of to carry out exploitations like Privilege Escalation. Currently, the operation supports the automated privilege escalations of CVE 2023-36802 and CVE 2023-21768.

RCE and Privilege Escalation Check
RCE and Privilege Escalation Check
This operation runs several checks on the target system for any potential privilege escalation/remote code execution vectors.

The operation was inspired by the tool Seatbelt (https://github.com/GhostPack/Seatbelt), and was created as a more light-weight version of the tool written in pure Powershell. It conducts five main checks : Operating System information, TCP Connections, Installed Applications, Processes, and Services. The information displayed by these checks can reveal potential vectors of privilege escalation/remote code execution through vulnerable services on the machine, or vulnerabilities within the operating system version itself.

Reflective PE Injection
Reflective Injection
This operation attempts to bypass anti-virus solutions and uploads a selected executable file into the target system's memory using reflective injection.

Reflective PE Injection is a sophisticated method of injecting PE (Portable Executable) files directly into the memory space of another process. This technique is commonly used by malware to avoid detection and enhance persistence by executing code without writing the payload to disk. Common payloads that are injected using this method are credential-stealing tools like Mimikatz, and powerful reverse-shell tools like Metasploit's Meterpreter.

Net NTLMv2 Hijacking
Net NTLMv2 Hijacking
This operation steals the Net NTLMv2 hash of the current logged on user, and attempts to obtain the corresponding plaintext password using a bruteforce/dictionary attack.

If this operation is deployed, the Net NTLMv2 hash will be captured by Wraith and then bruteforced using either a dictionary attack or a traditional bruteforce attack. If a password was successfully cracked, it will be displayed accordingly. A successful password crack might indiciate a weak password being used by the user in the target system. For more information, refer to the documentation.
